# Wake Experience — generation prompt set

Mode: OpenAI built-in image generation and reference-based image editing.

## Shared visual direction

Photorealistic 3D miniature diorama; premium architectural visualization; subtle tilt-shift depth; warm, slightly muted colors; clean modern small-business office; pale oak, charcoal metal, warm off-white, muted slate and soft teal; realistic materials and proportions; no cartoon or pixel-art treatment. Landscape 16:9 framing. No text, logos, brand names, readable markings, letters, numbers, symbols, or watermarks. People, where present, are small, distant, and faceless.
